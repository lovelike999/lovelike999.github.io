ffmpeg · 30 s / clip MoviePy · frame sampling fps = 5 audio = 16 kHz PCM WAV OpenCV · JPEG / Base64
ffmpeg / 30 s

16 kHz WAV

02

人物实体抽取：视觉与听觉并行

先形成稳定的 face / voice 节点，再交给 M3-Agent-Memorization。

Face branch

InsightFace buffalo_l
RetinaFace 检测人脸框，ArcFace 输出 512-D 身份特征。
det > 0.85 · quality > 22
最终质量门控，过滤误检、模糊脸和过小人脸，减少错误人物节点。
HDBSCAN ≥ 0.8 / 20
先筛掉低质量样本，再以 min_cluster_size=20 将同一 clip 中重复出现的人脸归簇。
τimg ≥ 0.30 · max 10
跨 clip 做同人重识别；达到阈值就复用 image node，并限制节点中的特征数量。
top 3 / cluster · CPU
每个角色最多保存 3 张高质量代表脸；CPU 模式避免占用 GPU 显存。

Voice branch

Gemini 1.5 Pro-002
联合执行语音分轨与 ASR，返回开始时间、结束时间和说话文本。
gap ≤ 0.6 s
合并同一说话人的相邻短句，避免一句话被拆成多个 voice 片段。
min duration = 2 s
剔除过短且声纹不稳定的语音，减少噪声和错误聚类。
ERes2NetV2 + FBank · 192-D
提取归一化说话人声纹，用于跨 clip 关联同一人物。
τaudio ≥ 0.60 · max 20
余弦相似度超过阈值就复用 voice node；限制每个节点最多保存 20 个向量。
pydub segmentation
按分轨时间边界提取真实音频段，供声纹模型计算。
输出稳定标识 <face_id> 与 <voice_id>，后续文本记忆通过这些实体 ID 建立可追溯连接。

03

M3-Agent-Memorization 生成两类记忆

联合使用视频、人脸证据、语音文本和时间戳生成可建图的 JSON memory。

模型同时输出 video_descriptions（原子事件）与 high_level_conclusions（高层推断、人物等价关系）。

Qwen2.5-Omni Thinker · 7B use_audio_in_video = True temperature = 1e−6 max_new_tokens = 4096 JSON schema constrained
M3-Agent-Memorization
同时阅读画面、人物证据和语音，生成 episodic 事件与 semantic 高层结论。
use_audio_in_video = True
在对齐视频时同步读取音轨，保留说话内容与视觉事件的对应关系。
temperature = 1e−6
近似贪婪解码，降低随机性，让 memory 内容更稳定且便于复现。
max_new_tokens = 4096
为事件列表与高层结论预留足够长度，降低输出被截断的概率。
JSON schema
将输出约束为可解析字段，直接进入文本向量化和图写入阶段。

04

文本向量化与多模态异构图写入

每条 memory 变成文本向量节点，并通过人物标签与 face/voice 实体相连。

使用 text-embedding-3-large 编码为 3072-D 向量；Episodic 每条新建节点， Semantic 根据实体一致性和余弦相似度决定增强、削弱或新建。

img / voice / episodic / semantic sim > 0.85 → reinforce (+1) sim < 0 → weaken (−1) otherwise → new node edge weight = 1.0
text-embedding-3-large · 3072-D
把事件和语义结论映射到统一向量空间，支持后续语义检索。
entity regex <…>
提取文本中的 face/voice ID，并建立文本节点到人物实体的双向边。
Episodic → new node
保留每个 clip 的独立事件和时间顺序，便于按时间或事件回溯。
Semantic sim > 0.85
视为高度一致的重复结论，增强已有节点连边而不重复添加。
Semantic sim < 0
视为冲突信号并削弱已有连接；当前实现不会为冲突结论新建节点。
otherwise → new semantic node
保存新知识；边初始权重为 1，后续通过增强/削弱累积证据。

Threshold Reference

clip = 30 s定义时间索引与检索粒度
fps = 5平衡动作覆盖与视觉计算成本
face ≥ 0.85 / 22保证最终人脸检测与质量可靠
face match ≥ 0.30跨片段进行同人重识别
voice ≥ 2 s排除过短且不可靠的语音
voice match ≥ 0.60跨片段关联同一说话人
semantic > 0.85合并重复结论并增强边权重
semantic < 0削弱彼此冲突的证据连接
text dim = 3072提供高容量的语义检索空间
temperature = 1e−6降低随机性并提高实验复现性
